# 🐾 Проект «Мяка» — Интерактивный сайт про котика

Добро пожаловать в репозиторий лабораторной работы №4! Это интерактивный одностраничный веб-сайт, посвященный очаровательному рыжему котенку по имени **Мяка**. 

## 🔗 Ссылка на проект
🚀 **[Посмотреть сайт вживую](https://maria-yogurt.github.io/-lab04/)**

---

## 🌟 Что умеет этот сайт:
* **Интерактивное мяуканье** — на сайте есть стильная оранжевая кнопка, при нажатии на которую котенок издает реалистичный звук «Мяу!».
* **Современный дизайн** — страница оформлена в виде аккуратной пастельной карточки с мягкими тенями.
* **Адаптивная верстка** — сайт одинаково красиво смотрится как на мониторах компьютеров, так и на экранах смартфонов.
* **Локальные ресурсы** — изображение котенка `ginger kitten.jpg` и аудиофайл `meow.mp3` хранятся прямо в репозитории, что обеспечивает моментальную загрузку.

---

## 🛠️ Стек технологий:
* **HTML5** — семантическая структура страницы.
* **CSS3** — стили, позиционирование карточки по центру экрана (`flexbox`) и анимация увеличения картинки при наведении (`hover container`).
* **JavaScript** — логика воспроизведения аудиодорожки через встроенный класс `Audio()`.
